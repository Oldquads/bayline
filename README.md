# Bayline

Car park test fits for Victorian sites.

Pick a lot on an OpenStreetMap base map (MapLibre + OpenFreeMap Positron), and Bayline lays out car parking on its title boundary, ranks the options by bay count, and checks them against Clause 52.06 (Victoria Planning Provisions) and AS/NZS 2890.1 / 2890.6.

- Map: OpenFreeMap · © OpenMapTiles · © OpenStreetMap contributors
- Lots, roads and addresses: Vicmap © State of Victoria, CC BY 4.0 (live from opendata.maps.vic.gov.au)

Test-fit only: ramps, grades, headroom, columns, sight distance and parking rates are not checked.
